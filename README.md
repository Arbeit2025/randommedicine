# ランダムお薬（randommedicine）

ボタンを押すと、一般用医薬品・よく知られた薬をランダムで1件表示する小さなツールです。既存の random 系列（randomdisease など）のお薬版です。

## 使い方

- **🎲 ランダムで薬を表示**：収録した全120件の薬からランダムに1件を選び、薬の名前と一緒に基本的な情報（分類・主な成分・効果効能・一般的なポイント）を表示します。
- **Wikipediaで詳しく見る**：その薬（成分）の Wikipedia ページを新しいタブで開きます。
- もう一度ボタンを押すと、別の薬が表示されます。

収録範囲は、解熱鎮痛薬、総合感冒薬、鎮咳去痰薬、鼻炎・アレルギー用薬、胃腸薬、整腸・止瀉薬、便秘薬、痔疾用薬、点眼薬、外用鎮痛消炎薬、皮膚用薬、口腔・のど用薬、乗物酔い薬、眠気防止・睡眠改善薬、滋養強壮・ビタミン剤、女性用薬など、一般用医薬品の主要カテゴリを幅広くカバーしています。

薬の情報は、一般的な知識をこのツール用に書き起こした内蔵データから表示します（添付文書などの本文の転載はしていません）。外部通信をしなくても動作します。具体的な用法・用量は記載していません。

> ⚠️ このツールは一般的な情報提供・学習のためのものです。医療上のアドバイスではなく、診断や治療の代わりにはなりません。薬の使用にあたっては添付文書をよく読み、用法・用量を守ってください。心配な症状がある場合や、妊娠中・授乳中・他の薬を使用中の場合は、自己判断せず薬剤師や医師に相談してください。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m pytest tests/
# または
python -m unittest discover -s tests
```

※ テストでは外部通信を行わず、内蔵データ（全120件・名前の重複なし・全フィールド充足）と画面表示を検証します。

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。
